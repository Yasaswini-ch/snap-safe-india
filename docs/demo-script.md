# Demo script (about 3 minutes)

A video is optional. The live site counts as a demo link, and this script also works for presenting live. Record the screen
with voice, and make a second take as a backup. Use only the made-up samples.

Before you start: open the live site a few minutes early so it is awake, and have the benchmark page section and the ID-card
sample ready.

| Time | Show | Say |
|---|---|---|
| 0:00 | The home page | People in India post photos with an Aadhaar number, a number plate or a UPI ID in the frame, and a stranger can use all of it. |
| 0:20 | The before and after slider | Same photo, before and after. Only the details that give you away are hidden. |
| 0:40 | Click the ID-card sample, "The agent at work" | The agent attacks the photo like a stranger, plans the fewest edits, edits, and attacks again. Watch the exposure report drop from exact to nothing. |
| 1:30 | The exposure report | It says what kind of detail showed and how precisely. It never prints the values. |
| 1:50 | The language dropdown, then the Telugu sign sample | The report can be in English, Telugu or Hindi, and it reads Telugu signs. |
| 2:10 | The benchmark section | Ten rendered Indian scenes with planted secrets. _Fill in the numbers once the run is done._ |
| 2:35 | The "What it looks for" cards | India is one region pack. A new country is one file. |
| 2:50 | The README or the Telegram chat, if it runs | It also works from a Telegram bot. |

Say these plainly:

- The photos in the benchmark are rendered, and every value is made up.
- "Verified" is the agent's own re-check, not proof.
- Edits are pixelation, so they look rough.
